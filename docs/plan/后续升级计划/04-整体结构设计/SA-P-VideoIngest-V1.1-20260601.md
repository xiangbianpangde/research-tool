## 2. 通信协议矩阵

| 通信对 | 协议 | 方向 | 数据格式 | 性能特征 | 错误处理 |
|--------|------|------|----------|---------|---------|
| M-001 → M-002..M-011 | in-process call | 同步/异步 | Python 对象 (dataclass) | 纳秒级 | 异常向上抛 |
| M-002 → deno/node/ffmpeg | subprocess + pipe | 单向 stdout | 文本 | ms~s 级 | returncode 非 0 → 错误码 |
| M-003 → yt-dlp | subprocess CLI + 进度回调 | stdout 实时流 | 文本 + JSON dump | 取决于视频大小 | 403/412 → 重试 ≤2 |
| M-005 → faster-whisper | in-process pybind | 函数调用 | numpy 数组 + List[Segment] | 计算密集 | OOM → 降档 |
| M-006 → Deepseek | HTTPS POST | 请求-响应 | JSON | 1-5s | 5xx → 切换 qwen |
| M-006 → Qwen fallback | HTTPS POST | 请求-响应 | JSON | 1-5s | 失败 → E_LLM_001 |
| M-008 → 既有管道 | subprocess pipe | stdin → stdout | 文本（pipe 协议） | 取决于管道 | 失败 → 重试 1 |
| M-009 → ffmpeg | subprocess CLI | 单次调用 | 文件 | 1-3s | 失败 → 静默跳过 |
| M-011 → 文件系统 | fsync 写文件 | append | JSON Lines | μs | 失败 → stderr |

## 3. 进程/线程模型

- **主进程**：单进程，asyncio 事件循环（research run 启动）
- **子进程（spawn）**：deno、node、ffmpeg、yt-dlp、whisper（pybind 可在主进程）、既有管道
- **线程**：无显式多线程（asyncio 已足够）；日志写入用 sync I/O（避免协程开销）
- **并发模型**：BP-011 用 `asyncio.gather` + `Semaphore(3)` 限制并发度
- **锁机制**：M-004 缓存使用 `asyncio.Lock`（单进程内），无需分布式锁
